# YoWriter-1.0

##YoWriter 1.0 project repository
A simple article writing program created by a hobbyest.

YoWriter is my personal project in learning Python. The Goal: create a lightweight article writing program that's not stuffed with crap I don't need. 

##About the Project

YoWriter started as a simple idea. A distraction free article writer that only contained the minimal stuff I wanted:
    - keywords
    - a place to write
    - and a spot to store tagline ideas
    - Arial only
And this is it.

##Built With
-Python
-Thonny
-Tkinter
